# دكان زمان — الموقع الرسمي (Dokan Zaman)

موقع شركة **دكان زمان للتوريدات العمومية** — شريككم الموثوق في التوريدات والتشغيل.
تصميم **Bold Bento**: مربعات بألوان الشعار (كحلي + برتقالي)، شريط تنقل ثابت، وزر واتساب عائم، ويعمل على الموبايل.

## فكرة البناء

الصفحة الرئيسية **نظرة عامة خفيفة**: كل قسم فيها يجيب عن سؤال واحد ويحوّل الزائر إلى الصفحة الداخلية التي فيها التفاصيل.

| القسم في الرئيسية | غرضه | التفاصيل في |
|---|---|---|
| الواجهة (Hero) | من نحن في جملة + زر «اطلب عرض سعر» + تتبع طلب نموذجي | صفحة من نحن |
| ماذا نورّد؟ | المجالات التسعة في كروت بالصور | صفحة مجالات التوريد |
| إدارة المشتريات | ثلاثة أرقام تلخّص الخدمة | صفحة من نحن |
| لماذا دكان زمان؟ | أربعة أسباب للثقة | صفحة من نحن |

## الصفحات

| الصفحة | الملف |
|---|---|
| الرئيسية | `index.html` |
| مجالات التوريد | `categories.html` |
| تواصل معنا (بيانات التواصل ونموذج طلب عرض السعر) | `contact.html` |
| من نحن (من نحن، الرسالة والقيم، كيف نعمل، إدارة المشتريات) | `about.html` |

## التشغيل

لا يحتاج المشروع إلى أي تثبيت أو أدوات بناء — افتح `index.html` في المتصفح مباشرة،
أو ارفع المجلد كما هو على أي استضافة ملفات ثابتة (مثل GitHub Pages).

## التقنيات

- **HTML + CSS + JavaScript** بدون مكتبات أو frameworks.
- خط **IBM Plex Sans Arabic** من Google Fonts.
- الأيقونات SVG مدمجة داخل الصفحة (رسمها مأخوذ من Lucide).
- الألوان معرّفة كمتغيرات CSS في أول ملف `css/style.css`.
- الأداء: الحركات تعتمد على `transform` و `opacity` فقط، والحركات المتكررة تتوقف عندما تكون خارج الشاشة، والصور بصيغة WebP وتُحمَّل عند الاقتراب منها.

## هيكل الملفات

```
*.html              الصفحات (index, categories, about, contact)
css/style.css       التنسيقات (كل الصفحات)
js/main.js          التفاعلات (كل الصفحات)
assets/             الشعار (فاتح/داكن) والصور
```

## ملاحظات

- روابط ملفات CSS و JS في كل الصفحات تنتهي برقم نسخة (`?v=...`). عند تعديل أي ملف منها غيّر هذا الرقم في كل الصفحات، حتى لا يعرض متصفح الزائر الملف القديم مع الصفحة الجديدة.
- شريط التنقل والفوتر مكرران داخل كل صفحة (لا توجد أداة بناء)، فأي تعديل عليهما يُطبَّق على كل الصفحات.
- بيانات التواصل (الهاتف `01006103696`، البريد info@ و sales@، العنوان) مكتوبة داخل كل صفحة: في صفحة «تواصل معنا» وفي الفوتر.
- زر واتساب العائم (أسفل يسار الشاشة) يفتح محادثة على الرقم `201006103696` برسالة جاهزة؛ لتغيير الرقم عدّل رابط `wa.me` في كل الصفحات.
- نموذج «اطلب عرض سعر» يفتح تطبيق البريد لدى الزائر برسالة جاهزة؛ الإرسال المباشر يحتاج خادمًا أو خدمة نماذج.
